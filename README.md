# Bonvoy Passport

A stamp-style check-in tracker for all 40 Marriott Bonvoy brands: tap a brand when you stay at it, stamp your passport, see your traveler archetype, and get suggestions for your next stamps with links to each brand's official page on marriott.com. To run it, just open `index.html` in a browser — no build step and no dependencies, with the brand logos as plain image files in `assets/`. To host it, drop the whole folder (including `assets/`) on any static host such as GitHub Pages.
